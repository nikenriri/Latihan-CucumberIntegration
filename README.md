**Web UI Automation Testing Framework (Saucedemo)**

Tugas ini merupakan kerangka kerja automatisasi testing WEB UI dengan BDD (Behaviour Driver Development.
Tugas ini dibuat untuk melakukan testing otomatis pada WEB UI (Sauce Demo), dengan menerapkan POM (Page Object Model) agar code mudah dipelihara.

**Tools yang digunakan**

Code editor : IntelLij IDEA
Bahasa pemrograman : Java dengan JDK 26.0.1
Kerangka kerja BDD : Cucumber (untuk menulis scenario pengujian dengan Gherkin)
Automatisasi Webdriver : Selenium webdriver
Menggunakan cucumber CLI untuk melakukan exekusi pengujian
